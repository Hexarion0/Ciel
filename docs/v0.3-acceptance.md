# v0.3 acceptance checklist

The short, hands-on version of [release checks](release-checks.md). Work through it
on the target desktop with the normal `.env`, then tag `v0.3` once every **blocker**
passes. Items marked *(nice)* can slip to v0.3.x with a note.

How to use it: tick a box when the expected result happens. When something fails,
write one line under the session's **Notes** (what you did, what happened) and keep
going. Run `ciel start dev` when you want logs for a failure. Don't put keys or private
audio in this file.

## 2. Voice basics (~20 min)

- [ ] "Hey Ciel" → acknowledgement → short question → one reply.
- [ ] "Hey Ciel, what time is it?" in one breath → start of the command kept, one reply, no web lookup.
- [ ] Wake rate: 10 normal-volume tries ___/10, 10 quiet tries ___/10. One minute of silence with the PC humming: ___ false wakes.
- [ ] Follow-up without the wake phrase uses earlier context.
- [ ] Pause ~1 s mid-sentence, then finish → one turn, not cut off.
- [ ] Interrupt a long reply with a new command → playback stops at once, new reply completes.
- [ ] `/stop` during playback and during a slow provider stream both stop cleanly.
- [ ] Stay silent after waking → returns to standby, nothing invented.
- [ ] "How do you say goodbye in Spanish?" gets an answer; "Goodbye" ends the follow-up.
- [ ] Ctrl+C exits; a fresh launch can open the mic again.

## 3. Ambient, streaming, and captions (~15 min)

- [ ] Talk to someone else nearby ("Mom, what's for dinner?") → Ciel stays quiet; no turn saved.
- [ ] "Ciel, stop listening" → wake-word mode; "Hey Ciel, listen continuously" → ambient again.
- [ ] Ask a question, then add "and also…" while it's thinking → one combined answer.
- [ ] Multi-sentence answer: first sentence plays before the full reply arrives. First-audio time from logs: ___ s.
- [ ] Interrupt, then "Ciel, continue" → resumes rather than starting over.
- [ ] Ask for code → code in history/captions, not read aloud. No `[stage directions]` spoken or shown.
- [ ] Captions reveal at speaking pace; interrupted lines end with `[interrupted]`.

Notes:

## 4. Memory (~20 min, plus a restart)

Use a throwaway fact if you don't want to change real ones.

- [ ] "Ciel, my favorite game is CS2" → proposal → "no" → nothing saved (`ciel memory search favorite game`).
- [ ] Repeat → "yes" → quit → restart → "What's my favorite game?" → CS2. **(blocker)**
- [ ] Propose a change, ask the time, then say "yes" → the stale proposal is *not* saved.
- [ ] Same after waiting 60+ s, and after "cancel".
- [ ] "What did we talk about last time?" after a restart → short factual recap, no replay of raw chat.
- [ ] `ciel memory pause` → personal facts no longer used in replies; `ciel memory resume` restores them.
- [ ] Forget the test fact by voice or `ciel memory forget` → no longer recalled, after a restart too.
- [ ] `ciel memory backup` to a new folder → both the `.db` and `.workspace/` exist.
- [ ] *(nice)* Leave Ciel running past 03:00 → `ciel memory review` shows a run; `apply` one action works.

## 5. Internet (~15 min)

- [ ] "What's in the news today?" without saying "search" → sourced answer; links support it.
- [ ] Current product price → sourced answer or an honest "couldn't verify".
- [ ] Ask Ciel to read a public article URL → summary from page text, plus link. A blocked page gets an honest explanation.
- [ ] Weather with no city configured → asks for a city; an explicit city later overrides it.
- [ ] Ask about a named show/release, then "can you search the latest one?" → query keeps the title.
- [ ] Interrupt a lookup → no stale answer or links attached to the next request.
- [ ] Network off: current-facts question → can't-verify + retry offer. Clock, memory readback, and opening an app still work offline. Network on → retry succeeds. **(blocker)**
